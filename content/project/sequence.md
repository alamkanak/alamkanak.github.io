![Sequence browser video editor with a multitrack timeline and AI editing through MCP](/sequence.png)

Sequence is a free, open-source video editor that runs in the browser. Import local media, arrange clips on a multitrack timeline, add titles and music, and export on your own device without signing up or uploading your files.

## A complete editing workflow

Trim, split, and arrange video, audio, and images. Add text, shapes, gradients, animations, and transitions, adjust playback speed, and shape audio with volume points. Preview your work and export MP4 or WebM with no watermark.

## Edit with AI agents through MCP

Connect Claude Code, Codex, Cursor, or another compatible AI agent through Sequence's local MCP server. Ask for edits in plain language, then review, adjust, or undo the changes in the same timeline you use by hand.

> Trim the opening, add a title, and fade the music out.

The agent can arrange clips, trim footage, add titles, and adjust audio. Rendering stays in the browser; the agent receives project data and any previews it requests.

## Built for everyday editing

Resizable panels, timeline snapping, undo and redo, keyboard shortcuts, a command palette, and light and dark themes keep the workspace adaptable. Media and the current project autosave in browser storage, with file relinking available when original media goes missing.

## Local media, open source

Media processing and export happen on your device. The project is licensed under AGPL-3.0-only, with source code and MCP setup documentation available for developers who want to explore or extend it.
